# 数字相位计的测量语义与理论模型

## 适用场景

- 给测量结果写断言/判据，需要知道"理论值是多少、允许多大偏差、为什么"。
- 排查实测与理论对不上：先分清是量化下界、握手开销，还是真实缺陷。
- 规划闸门时间、时钟频率等参数（含未来的 AXI 寄存器与 PS 侧可变闸门时间）。

## 一次测量的时序

`Controller` 的低速 FSM 与 `PhaseMeter` 通过 valid-ready 握手：

| 阶段 | 发生的事 |
| --- | --- |
| `idle` | 闸门计数器清零并停用；两个测量计数器清零（`clearCnt = stateReg === idle`）；`in.valid` 到来时发出 `start` 请求 |
| `waitStart` | `PhaseMeter` 等到参考信号 `sig1` 的上升沿，回 `start` 响应 |
| `measuring` | 闸门计数器开始按低速时钟累加；`edgeCnt` 在 `sig1` 上升沿累加；相位计数在 `sig1` 上升沿使能、在 `sig2` 上升沿停用 |
| `waitStop` | 闸门计数达到 `in.bits.targetGate` 后发出 `stop` 请求，`PhaseMeter` 等到 `sig2` 的下一个上升沿才回响应 |
| 锁存 | 收到 `stop` 响应后把 `edgeCnt` / `phaseCnt` / 当前 `gateCnt` 写入输出负载，`out.valid` 拉高**一个**低速周期，回到 `idle` |

要点：

- 测量窗口的关闭依赖**被测信号的下一个上升沿**，所以两个输入必须是自由运行的周期信号；一次性脉冲会挂住握手。
- `targetGate` 在测量期间必须保持不变。
- 计数器只在 `idle` 清零，因此连续测量之间不需要额外复位，但每次都从零开始。

## 三个观测量

| 输出 | 单位 | 语义 |
| --- | --- | --- |
| `gateCnt` | 低速时钟周期 | 测量窗口的实际长度 |
| `edgeCnt` | 个 | 窗口内 `sig1` 的上升沿数 |
| `phaseCnt` | 高速时钟周期 | 每个参考周期内「`sig1` 上升沿 → 下一个 `sig2` 上升沿」间隔的累加值 |

## 理论值与容限

设低速时钟周期 `T_clock`、高速时钟周期 `T_dsp`、参考信号周期 `T_sig1`、被测信号周期 `T_sig2`、相位偏移（`sig2` 上升沿相对 `sig1` 上升沿）为 `offset`，目标闸门计数为 `targetGate`：

| 观测量 | 理论值 | 容限 | 余量来源 |
| --- | --- | --- | --- |
| `gateCnt` | `targetGate` | `round(T_sig2 / T_clock) + 1` | 闸门到达目标值后还要等 `sig2` 的下一个上升沿，再经若干低速周期完成锁存 |
| `edgeCnt` | `targetGate × T_clock / T_sig1` | `±2` | 窗口边界与被测频率不整除，可能多算/少算一个沿；实际窗口比目标闸门长（含停止握手），边沿数因此系统性偏多一个左右 |
| `phaseCnt` | `(offset / T_dsp) × edgeCnt` | `±edgeCnt` | 每个参考周期的计数只能取整数，误差上限 1 个高速时钟周期 |

推导时可用的几条等价说法：

- `edgeCnt` 的理论值就是"窗口长度 ÷ 参考周期"，窗口长度约等于 `gateCnt × T_clock`。
- `phaseCnt / edgeCnt` 是相位偏移对应的高速时钟周期数，乘以 `T_dsp` 即绝对相位差，除以 `T_sig` 即相位差占比（× 360° 得到度数）。**判据优先写在 `phaseCnt / edgeCnt` 这个比值上**，它与闸门时间无关，便于比较不同闸门时间下的结果。
- 相位分辨率是 1 个高速时钟周期：200MHz 下对 400ns 周期约 4.5°，对 1µs 周期约 1.8°。式中的 `±1 cycle / 参考沿` 是这个分辨率的量化下界，不是设计余量。

## 相位映射成立的条件

`phaseCnt` 与相位偏移一一对应的前提是 **`offset < T_sig / 2`**：参考沿之后若在半个周期内没等到被测沿，就会跨到下一个被测周期，读数不再线性映射到相位差。写扫描用例时把偏移限制在半个周期内（`test/Controller.cpp` 的相位用例即按此约束取参数）。

## 位宽决定参数上限

`Controller(gateCntWidth = 28, edgeCntWidth = 32, phaseCntWidth = 32)`，低速时钟 50MHz、高速时钟 200MHz 时：

| 量 | 上限 |
| --- | --- |
| 闸门计数 | `2^28 - 1` 个低速周期 ≈ 5.37 s |
| 相位计数 | `2^32` 个高速周期 ≈ 21.5 s 的连续累加 |
| 边沿计数 | `2^32` 个参考沿 |

`targetGate` 与闸门计数器同为 28 位（`UInt(gateCntWidth.W)`），所以 5.37 s 是**可达上限**而不是饱和点：想要更长的闸门时间必须同时加宽 `gateCntWidth` 与 `targetGate` 的位宽。`in.bits.targetGate` 在测量期间必须保持不变。`DspCounter` 另有一条 `width <= 48` 的约束，加宽时两处都要改。

## 已知局限

- **一个周期固定偏一格检测不出来**：容限恰好等于量化下界，`phaseCnt` 每个参考周期固定多/少 1 个高速周期时，判据仍然通过。要覆盖这类系统性偏差，需比较两个不同闸门时间的结果（误差不随闸门时间线性增长即异常），或提高高速时钟频率。
- **仿真中的两个时钟是整数比（20ns : 5ns）且相位对齐**，没有真正激励跨时钟域路径的抖动与异步。片内信号源虽然以 DSP 域时钟为时基，但在仿真里它同样由理想时钟驱动（MMCM 的抖动、相位噪声没有建模），上板后的实际精度还要把 MMCM 抖动算进去。
- **片内信号源是最好的自校验激励**：它的相位差被设定为 `SIG_PHASE / SIG_FREQ` 个高速时钟周期，是一个整数，且两路信号与测量核心同源，因此 `phaseCnt / edgeCnt` 应当**精确等于**这个整数（容差只剩边沿检测通路的固定延迟差），比外部信号更容易判定「相位读数是否正确」。用它扫描相位字即可标定 `phaseCnt / edgeCnt` 的比例关系。
- **相位读数与两个时钟域的周期比无关**（相位计完全在高速域内测量参考沿到被测沿的间隔），因此低速时钟改频只影响闸门时长和 `gateCnt`，不影响 `phaseCnt / edgeCnt`。
- 闸门时间越长，随机量化误差在平均中抵消得越充分（本项目取 2000 个低速周期 ≈ 40µs）。短闸门时间下容限公式不变，但相对误差明显变大。

## 怎么用

- 写 Verilator 断言时用 `verilator_utils::approx` 表达上表的容限（用法见 `dpm-verilator-testing`）。
- 后仿、片内测试与 PS 侧校验应复用同一套公式与容限，避免"仿真里宽松、实测时严格"的两套标准。
- 结论里要区分"落在量化下界内"和"完全一致"：前者是设计允许的，后者不应当作为通过标准。
